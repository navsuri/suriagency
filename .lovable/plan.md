

# ADN Marketer Agency — Dark 3D Profile Page

## Overview
A professional, dark-themed single-page profile for **ADN Marketer Agency** (website selling & agent selling) with a futuristic 3D aesthetic inspired by the reference sphere image.

## Design
- **Dark background** (#0a0f1a) with subtle blue/cyan glowing accents
- **Color palette**: Dark navy, cyan/teal highlights, white text
- **Typography**: Bold modern headings, clean body text
- **Glowing effects**: CSS glow, gradients, and animated elements throughout

## Sections

### 1. Hero Section
- Large interactive **3D rotating sphere** (React Three Fiber) with metallic striped texture matching the reference image
- Agency name "ADN Marketer Agency" displayed prominently with glow effect
- Tagline: selling websites & agent services
- CTA button with glow hover effect

### 2. About Section
- Brief agency description with animated fade-in
- Key stats (projects completed, clients served, etc.) with glowing cards
- Dark glassmorphism card styling

### 3. Services Section
- Service cards for: Website Selling, Agent Selling, Digital Solutions
- Each card with icon, title, description
- Hover effects with cyan glow borders
- CSS 3D tilt/perspective effects on hover

## Technical Approach
- **React Three Fiber** for the interactive 3D sphere in the hero
- **CSS animations** for glow effects, floating particles, and smooth scrolling
- **Responsive** design for all screen sizes
- Single-page layout with smooth scroll navigation
